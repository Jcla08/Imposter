### What is it?
In late 2025, the "Imposter" trend took off. It featured a social deduction game where players were given a wordand had to find the one player without the word. I created a device out of affordable componets. 
### Why?
After seeing the game being played on instagram I tested it with my family! I couldn't help but wish I could customize the word sets without a subscription fee. So I built an affordable version out of parts I had laying around.
### How it Works
On startup you are asked to input the number of players. You can use the rotary encoder to increase and decrease the amount. Use it's button to continue. You will be prompted to select a category with the rotary encoder. Pass the device around using the encoder button to show and hide the word. Use the button the reveal the imposter.
